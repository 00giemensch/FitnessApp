# FitnessApp

![FitnessApp Demo](fitnessGif.gif)

iOS приложение для отслеживания тренировок и статистики упражнений.

## Описание

FitnessApp позволяет пользователям:

- Выбирать упражнения из базы данных Wger API
- Записывать результаты тренировок (подходы и повторения)
- Отслеживать статистику по каждому упражнению
- Устанавливать цели и отслеживать прогресс
- Просматривать графики прогресса за различные периоды

## Технологии

- **Язык:** Swift
- **Минимальная версия iOS:** 15.0+
- **Архитектура:** MVVM + Coordinator
- **Хранение данных:** Core Data
- **API:** [Wger API](https://wger.de/) для получения упражнений

### Основные компоненты

- **MVVM + Coordinator** - разделение логики (ViewModel) и представления (ViewController) с централизованным управлением навигацией
- **Repository Pattern** - абстракция работы с данными для слабой связанности
- **CoreDataManager** - синглтон для работы с Core Data

## Основные функции

### 1. Главный экран

- Приветствие и быстрый доступ к функциям
- Кнопка начала тренировки

### 2. Тренировка

- Выбор упражнения
- Добавление подходов с количеством повторений
- Сохранение результатов тренировки

### 3. Статистика

- Список всех упражнений с историей тренировок
- Детальная статистика по каждому упражнению:
  - Общее количество повторений
  - Лучший результат за подход
  - График прогресса (день, неделя, месяц, 6 месяцев, год)
- Установка целей (общее количество повторений, лучший результат)

### 4. Инструкции

- Просмотр категорий упражнений из Wger API
- Детальная информация об упражнениях
- Изображения и описания

## Структура данных

### Core Data Entities

- **WorkoutEntity** - тренировка (дата, упражнение, подходы)
- **WorkoutSetEntity** - подход (количество повторений, дата)
- **WorkoutGoalEntity** - цель (тип цели, значение)

## Архитектурные решения

### Repository

Проект использует паттерн Repository для абстракции работы с данными

Это обеспечивает:

- Слабую связанность между слоями
- Легкое тестирование (можно подменить реализацию)
- Возможность добавления новых источников данных (например, RemoteRepository)

### Coordinator

Навигация управляется через `AppCoordinator`, что позволяет:

- Централизованно управлять переходами
- Легко изменять навигацию
- Изолировать ViewControllers от навигационной логики
